Forma Studio

A responsive creative-studio landing page built with React and Tailwind CSS.



Run locally
npm install
npm run dev

project structure


vite-project/
├── public/                 
└── src/                    
    ├── assets/             
    ├── components/       
    │   └── icons/          
    ├── pages/

Fully Responsive Layout:Seamless user experience across mobile, tablet, and wide desktop screens.
Blazing Fast Performance:Powered by Vite for near-instantaneous hot module replacement (HMR) and optimized builds.
Component-Driven Design: Modular architecture using atomic React components for high reusability.
Modern Typography & UI:Clean layout styles leveraging Tailwind utility classes to match modern web design standards.
